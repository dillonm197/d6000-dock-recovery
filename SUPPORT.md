# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/dillonm197/d6000-dock-recovery/issues) to track
bugs, compatibility reports and feature requests. Please search the existing issues before filing a
new one, to avoid duplicates. For a new issue, pick the form that fits; each one asks for the logs
needed to look into it.

For questions about using the tool, open an issue as well.

## Support policy

This is a volunteer project. There's no guaranteed response time, and it isn't supported by Dell
or Apple.
