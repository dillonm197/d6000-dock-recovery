# Code of conduct

This project has adopted the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).

To report unacceptable behaviour, contact the maintainer privately through GitHub (for example
with the repository's **Report a vulnerability** form when it needs to stay private), or use
GitHub's **Report content** option on the comment or issue. Reports are handled confidentially.
